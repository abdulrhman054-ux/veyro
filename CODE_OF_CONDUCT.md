# Code of Conduct

We want Veyro to be a welcoming project for everyone, in Arabic and in English.

## Our pledge
- Be respectful and patient. Many contributors are new to open source, to trading, or to one of the two languages.
- Critique code and ideas, never people.
- Assume good intent, and ask before assuming.
- No harassment, discrimination, personal attacks, or sexual or violent language.
- Don't share anyone's private information.
- No financial promotion: don't use issues or PRs to push stocks, paid signals, referral links or "guaranteed returns".

## Scope
This applies to issues, pull requests, discussions, reviews and any other project space. It also applies when you represent the project elsewhere.

## Enforcement
Report problems privately to the maintainer through GitHub (open a private security advisory, or contact **@abdulrhman054-ux**). Reports are handled confidentially.

The maintainer may edit or remove content, warn, or temporarily or permanently ban anyone who breaks these rules.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
